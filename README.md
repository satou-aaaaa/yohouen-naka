# 予報円のなか（yohouen-naka）

台風の予報円を見て、同じ予報の台風を何本も流したら、円に入るのは何本くらいかを当てる1日5問の学習ゲーム。答えのあとに進路が1本ずつ流れ、入った本数と外に出た本数を数え上げる。予報円は、予報した時刻に台風の中心が約70%の確率で入る範囲（気象庁）。円の外に出る進路も3割ほどある。円が大きい＝台風が大きくなる、ではない。

遊ぶ: <https://satou-aaaaa.github.io/yohouen-naka/>

- 予報円の意味（中心が入る確率は70%・円の大きさは進路の予報の不確実性）は、気象庁「台風情報の種類と表現方法」<https://www.jma.go.jp/jma/kishou/know/typhoon/7-1.html> と「予報用語 台風」<https://www.jma.go.jp/jma/kishou/know/yougo_hp/haichi2.html> によります。
- 本数の数え方は目安です（進路のずれを正規分布と置き、半径が予報円の k 倍の円に入る割合 ＝ 1 − 0.3^(k²)）。流れる進路は練習のための例で、本物の台風の記録ではありません。
- 今日の5問と「ためす」の乱数は日付の種で決まり、だれでも同じ進路が流れます。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。結果の「共有」を押したときだけ、その日の回の番号と各問の○×の並びが、選んだサービス（X・LINE など）に渡ります。
